# Learning Playwright

A comprehensive learning project for Playwright testing framework and JavaScript concepts.

## Project Structure

```
LearningPlaywright/
├── Chapter_01_Basics/
│   ├── 01_Basic.js
│   ├── 02_JS_Step_By_Step.js
│   ├── 03_verify_setup.js
│   └── 04_hot_code.js
└── Chapter_02_Java_Concepts/
```

## Chapters Overview

### Chapter 01: Basics
Introduction to Playwright and JavaScript fundamentals:
- Basic setup and configuration
- Step-by-step JavaScript concepts
- Setup verification
- Hot code reloading

### Chapter 02: Java Concepts
Deep dive into Java concepts and their applications.

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/chandupatlasapna50-lgtm/LearningPlaywright.git
```

2. Navigate to the project:
```bash
cd LearningPlaywright
```

3. Install dependencies (if needed):
```bash
npm install
```

## Requirements

- Node.js (v14 or higher)
- npm or yarn
- Playwright

## Usage

Run individual scripts from the chapter directories:
```bash
node Chapter_01_Basics/01_Basic.js
```
